# 🌱 Labé Market

Application mobile Flutter permettant de connecter les producteurs agricoles de Labé avec les acheteurs.

## 🚀 Objectif
Faciliter l’accès au marché pour les producteurs locaux grâce au numérique.

## 📱 Fonctionnalités
- 🧑‍🌾 Publier un produit
- 🛒 Consulter les produits
- 📞 Contacter les producteurs
- 📡 Mode hors ligne (simulation SMS)
- 🔊 Assistance audio en langue locale

## 🧠 Technologies utilisées
- Flutter
- Firebase (Firestore)
- UI Premium (Design moderne)

## 🎯 Hackathon
Projet réalisé dans le cadre du hackathon Labé 2026.

---

## 💡 Impact
Une solution conçue pour fonctionner même dans les zones à faible connectivité.
